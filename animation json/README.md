# Animations Lottie (accueil)

Place ici les fichiers **`.json`** exportés depuis After Effects / LottieFiles.

## Fichier actif

**`8f577fd4-f1aa-11ef-b996-b3631e05cc15.json`** — affiché au-dessus du titre sur l’accueil, en boucle.

## Changer d’animation

1. Copie le `.json` dans ce dossier (si besoin).
2. Dans `src/data/heroLottieAnimations.ts`, mets à jour l’import et `HERO_LOTTIE_FILE` :

```ts
import heroLottieJson from '../../animation json/TON_FICHIER.json';

export const HERO_LOTTIE_FILE = 'TON_FICHIER.json';
```

3. Relance `npm run dev`.
